# Рабочий стол писателя

Приложение для написания книги на iPhone: книжная вёрстка, главы и части, поиск, карточки героев и событий, обложки, сохранение в PDF.

Открыть: https://76rk9hckb8-code.github.io/kniga/

Текст книги хранится только на устройстве, на сайт он не попадает.

## Моя полка

Трекер чтения: полки, прогресс по страницам, процентам, главам или аудио, дневник, статистика и цель на год.

Открыть: https://76rk9hckb8-code.github.io/kniga/chtenie/

## Мой путь к 65

Еженедельный вес с прогрессом до цели и наградой, тренировки и еда с водой в свободной форме.

Открыть: https://76rk9hckb8-code.github.io/kniga/ves/
